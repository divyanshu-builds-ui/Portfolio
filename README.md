# Portfolio — Divyanshu Gupta

Modern developer portfolio built with React + Vite + Tailwind CSS.

## Structure

```
├── client/     → React frontend (Vite + Tailwind)
├── server/     → Express backend (Nodemailer for contact form)
```

## Quick Start

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
```

## Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, Framer Motion, React Icons
- **Backend:** Express, Nodemailer
- **Deployment:** Vercel
